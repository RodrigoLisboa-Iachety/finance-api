# Finance API

API REST para gerenciamento financeiro desenvolvida com Java 21 e Spring Boot.

## Tecnologias

- Java 21
- Spring Boot 3
- Spring Web
- Spring Data JPA
- Bean Validation
- H2 Database
- Maven
- Lombok

## Funcionalidades

- Criar transações
- Listar transações
- Buscar transação por ID
- Atualizar transações
- Excluir transações
- Validação de dados
- Tratamento global de exceções
- DTOs para requisição e resposta

## Como executar

Clone o repositório:

```bash
git clone https://github.com/RodrigoLisboa-Iachety/finance-api.git
```

Entre na pasta do projeto:

```bash
cd finance-api
```

Execute a aplicação:

```bash
./mvnw spring-boot:run
```

A aplicação estará disponível em:

```
http://localhost:8080
```
